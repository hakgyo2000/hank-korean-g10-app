1. 다운로드 — Mac 종류에 맞게 선택

Apple Silicon (M1/M2/M3) Intel Mac
버튼을 누르면 최신 릴리스 페이지로 이동합니다. 자신의 Mac 종류에 맞는 zip 파일을 내려받아 압축을 해제해주세요. (Mac 종류는 • 왼쪽 위 애플 로고 → 이 Mac에 관하여에서 확인 가능)

2. 첫 실행 시 "손상되었습니다" 경고가 뜨면

1) 터미널(Terminal) 앱 실행
2) 아래 명령어 입력 후 Enter (경로는 실제 앱 위치에 맞게 드래그해서 넣어도 됩니다)
xattr -cr "/Applications/Hank Korean G10.app"
3) 앱을 다시 실행

Apple 개발자 인증서가 없는 앱이라 macOS가 보내는 보안 경고입니다. 위 명령어는 격리(quarantine) 속성만 제거하며 앱 내용은 바뀌지 않습니다.

3. 이후 업데이트

앱을 실행할 때마다 자동으로 새 버전을 확인하고, 있으면 백그라운드에서 내려받아 안내합니다. 별도로 이 페이지에 다시 올 필요는 없습니다.

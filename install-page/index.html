1. 다운로드 — Mac 종류에 맞게 선택

Apple Silicon (M1/M2/M3) Intel Mac
버튼을 누르면 항상 최신 버전 설치 파일(.pkg)이 바로 다운로드됩니다. (Mac 종류는 • 왼쪽 위 애플 로고 → 이 Mac에 관하여에서 확인 가능)

2. 설치 — 다운로드된 파일을 더블클릭

1) 다운로드된 .pkg 파일을 더블클릭
2) "확인되지 않은 개발자" 경고가 뜨면 → 완료 버튼 클릭
3) 시스템 설정 → 개인정보 보호 및 보안 화면 맨 아래로 스크롤 → 확인 없이 열기 클릭 (Mac 암호 또는 지문 필요)
4) 다시 .pkg 파일을 더블클릭 → 설치 마법사가 열리면 계속 → 설치

Apple 개발자 인증서가 없는 앱이라 macOS가 처음 한 번 보내는 보안 확인 절차입니다. 터미널은 전혀 필요 없고, 설치가 끝나면 이 앱은 이후 완전히 정상적으로 바로 열립니다.

3. 이후 업데이트

앱을 실행할 때마다 자동으로 새 버전을 확인하고, 있으면 백그라운드에서 내려받아 안내합니다. 별도로 이 페이지에 다시 올 필요는 없습니다.
